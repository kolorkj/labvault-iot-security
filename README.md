# NEXUS LabVault — IoT Laboratory Equipment Security System

**Status:** Work in Progress — Hardware Integration & Debugging

## Project Overview

NEXUS LabVault is a university project developing an Arduino-based security and monitoring system for laboratory equipment. The system is designed to detect unauthorized access and abnormal movement, activate local alerts, and support cloud-based event monitoring.

## Technologies & Hardware

- Arduino Uno
- ESP-01 Wi-Fi module
- ThingSpeak IoT platform
- Magnetic reed, touch, shock, and tilt sensors
- LED and buzzer alert components

## Planned Features & Expected Results

The intended prototype will:

- Detect unauthorized equipment access and movement.
- Trigger local LED and buzzer alerts.
- Apply an authorized-access window to distinguish expected handling from suspicious activity.
- Transmit security events to ThingSpeak for remote monitoring.
- Undergo integration testing and reliability evaluation.

These are **development goals**, not completed or validated system capabilities.
